## Deskripsi
Projek ini mengaplikasikan 3 jenis algoritma pencarian local search yang ada
1. Hill Climbing -> Steepest Ascent, Stochastic, dan Sideways Move
2. Simulated Annealing
3. Genetic Algorithm

## Setup
Untuk install semua dependency, gunakan command:
```
pip install requirements.txt
```

## Run Program
Melakukan local search
1. Pada folder root, gunakan command:
   ```
   python src/main.py
   ```
2. Pilih jenis algoritma yang ingin digunakan

## Bonus yang Dikerjakan
1. Objective function (3 poin)
